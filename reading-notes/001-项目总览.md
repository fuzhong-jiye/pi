# 001 - Pi Agent Harness 项目总览

## 项目定位

**Pi Agent Harness** 是一个 coding agent（编程智能体）monorepo，核心产品是名为 **pi** 的可扩展终端编程助手。采用 lockstep 版本管理，当前版本 0.0.3。

---

## 顶层目录

| 路径 | 说明 |
|------|------|
| `packages/` | 核心代码，4 个子包 |
| `scripts/` | 构建/检查/发布/统计分析等脚本 |
| `.pi/` | pi 自身的配置目录（扩展、提示词模板、技能） |
| `.github/` | GitHub issue 模板、CI/CD workflows、贡献者白名单 |
| `AGENTS.md` | 项目开发规范（给人和 AI 智能体看的） |
| `CONTRIBUTING.md` | 贡献指南（包括新贡献者自动关闭 issue 的规则） |
| `biome.json` | 代码格式化/lint 配置 |
| `tsconfig.json` / `tsconfig.base.json` | TypeScript 配置 |
| `package.json` | 根 workspace 配置、脚本定义 |
| `test.sh` | 运行测试（跳过需要 API key 的 LLM 测试） |
| `pi-test.sh` | 从源码运行 pi |

## 四大核心包

### 1. `packages/ai` — `@earendil-works/pi-ai`

统一多供应商 LLM API，提供跨 OpenAI、Anthropic、Google、Mistral、Azure、Vertex AI、DeepSeek 等的一致的流式/非流式调用接口。

| 文件/目录 | 说明 |
|-----------|------|
| `src/types.ts` | 核心类型定义（消息、工具、事件流） |
| `src/models.ts` / `src/models.generated.ts` | 模型自动发现与注册 |
| `src/api-registry.ts` | API 注册中心 |
| `src/providers/` | 各 LLM 供应商实现（anthropic.ts, openai-completions.ts, openai-responses.ts, google.ts, mistral.ts 等） |
| `src/images.ts` / `src/images-api-registry.ts` | 图像生成 API |
| `src/cli.ts` | OAuth/API key 登录命令行 |

### 2. `packages/agent` — `@earendil-works/pi-agent-core`

带状态的智能体运行时，基于 `pi-ai` 构建，负责工具调用、事件流、消息管理和上下文处理。

| 文件/目录 | 说明 |
|-----------|------|
| `src/agent.ts` | Agent 主类，管理会话历史和 LLM 交互 |
| `src/agent-loop.ts` | Agent 循环逻辑（prompt → LLM → tool calls → loop） |
| `src/types.ts` | Agent 事件、消息类型定义 |
| `src/harness/` | 编码智能体的工具执行脚手架（bash、文件操作、会话管理等） |
| `src/harness/agent-harness.ts` | 主工作流编排 |
| `src/harness/skills.ts` | 技能系统 |
| `src/harness/prompt-templates.ts` | 提示词模板 |
| `src/harness/session/` | 会话持久化 |

### 3. `packages/coding-agent` — `@earendil-works/pi-coding-agent`

最终产品：交互式终端编码助手 CLI，整合了 agent、tui、ai 三个包。

| 文件/目录 | 说明 |
|-----------|------|
| `src/main.ts` | 入口，启动逻辑 |
| `src/config.ts` | 全局配置管理 |
| `src/core/agent-session.ts` | 会话核心（最复杂的文件） |
| `src/core/session-manager.ts` | 会话管理器（创建、恢复、分支、压缩） |
| `src/core/settings-manager.ts` | 设置管理 |
| `src/core/model-registry.ts` / `model-resolver.ts` | 模型注册与解析 |
| `src/core/extensions/` | 扩展系统（用户自定义工具/钩子） |
| `src/core/tools/` | 内置工具（read、bash、edit、write 等） |
| `src/core/compaction/` | 会话自动压缩（上下文窗口管理） |
| `src/core/export-html/` | 导出会话为 HTML |
| `src/cli/` | CLI 参数解析、会话选择器、模型列表 |
| `src/modes/` | 四种运行模式（interactive、print/JSON、RPC、SDK） |
| `src/package-manager.ts` / `package-manager-cli.ts` | pi packages 管理 |
| `src/utils/` | 各种工具函数 |
| `src/migrations.ts` | 数据迁移 |
| `docs/` | 完整文档 |
| `examples/` | 扩展示例 |

### 4. `packages/tui` — `@earendil-works/pi-tui`

终端 UI 框架，基于差异渲染（differential rendering），为 pi 提供无闪烁终端界面。

| 文件/目录 | 说明 |
|-----------|------|
| `src/tui.ts` | TUI 主容器 |
| `src/terminal.ts` / `src/utils.ts` | 终端抽象与工具 |
| `src/components/` | 内置组件（Text、Editor、Markdown、Input、SelectList 等） |
| `src/keybindings.ts` / `src/keys.ts` | 键盘绑定系统 |
| `src/autocomplete.ts` | 自动补全 |
| `src/terminal-image.ts` | 终端内图片渲染（Kitty/iTerm2 协议） |

## 架构关系

```
┌─────────────────────────────────────┐
│       pi-coding-agent (CLI)          │  ← 最终产品
│  交互 / 打印 / RPC / SDK 四种模式     │
├──────────────┬──────────────────────┤
│  pi-agent    │      pi-tui          │  ← 中间层
│  (智能体运行时) │    (终端 UI 框架)    │
├──────────────┤                      │
│    pi-ai     │                      │  ← 底层
│ (统一 LLM API)│                      │
└──────────────┴──────────────────────┘
```

依赖关系：`coding-agent` → `agent` + `tui` + `ai`，`agent` → `ai`。
